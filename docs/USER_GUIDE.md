# CMC Nouacour Library User Guide

## Getting Started

### Registration and Login

1. **Create an Account**
   - Click "Sign Up" on the homepage
   - Fill in your username, email, and password
   - Click "Create Account"

2. **Login**
   - Enter your email and password
   - Click "Login"

3. **Profile Setup**
   - Go to your profile page
   - Add an avatar image (optional)
   - Update your information as needed

## Library Features

### Browsing Books

1. **View All Books**
   - Click "Library" in the navigation menu
   - Browse through the book collection
   - Use the search bar to find specific books

2. **Search and Filter**
   - Use the search bar to search by title or author
   - Filter books by category using the dropdown
   - Combine search and filters for precise results

3. **Book Details**
   - Click on any book to view details
   - See book information, description, and download count
   - View the book cover image

### Reading Books

1. **Opening a Book**
   - Click "View Details" on any book card
   - The book will open in the built-in PDF viewer
   - Use the navigation controls to move through pages

2. **Bookmarking Pages**
   - While reading, click the bookmark button
   - Your bookmarks are saved to your profile
   - Access bookmarks from your profile page

3. **Downloading Books**
   - Click the download button on book details
   - The PDF will be saved to your device
   - Download count increases automatically

## Meeting Features

### Creating Meetings

1. **Schedule a Meeting**
   - Go to the "Meetings" page
   - Click "Create Meeting"
   - Fill in meeting details:
     - Title (required)
     - Description (optional)
     - Date and time
     - Duration (15 minutes to 4 hours)

2. **Meeting Settings**
   - Choose appropriate duration
   - Add a descriptive title
   - Include relevant details in description

### Joining Meetings

1. **View Available Meetings**
   - Go to the "Meetings" page
   - See all scheduled meetings
   - Filter by status (scheduled, ongoing, completed)

2. **Join a Meeting**
   - Click "Join Meeting" on any active meeting
   - You'll be taken to the meeting room
   - Meeting status updates automatically

3. **Meeting Room Features**
   - Real-time chat with other participants
   - See who's currently in the meeting
   - Typing indicators show when someone is typing

## Chat Features

### Real-time Messaging

1. **Sending Messages**
   - Type your message in the chat input
   - Press Enter or click Send
   - Messages appear instantly for all participants

2. **Message Types**
   - Text messages (default)
   - File attachments (if enabled)
   - Image sharing (if enabled)

3. **Chat History**
   - All messages are saved during the meeting
   - View message history when joining
   - Messages persist after meeting ends

### User Interaction

1. **Online Status**
   - See who's currently online
   - Green indicator shows active users
   - Gray indicator shows offline users

2. **Typing Indicators**
   - See when someone is typing
   - "User is typing..." appears briefly
   - Multiple users typing shown as "2 users typing..."

## Profile Management

### Updating Profile

1. **Edit Information**
   - Go to "Profile" page
   - Click "Edit Profile"
   - Update username, email, or avatar
   - Click "Save Changes"

2. **Avatar Upload**
   - Click on your current avatar
   - Select a new image file
   - Image will be uploaded and updated

3. **Account Settings**
   - View your account information
   - See your role and permissions
   - Check account creation date

## Navigation

### Main Menu

- **Home**: Return to the homepage
- **Library**: Browse and search books
- **Meetings**: View and join meetings
- **Profile**: Manage your account

### User Menu

- **Profile**: Edit your profile
- **Logout**: Sign out of your account

## Tips and Best Practices

### For Readers

1. **Search Tips**
   - Use specific keywords for better results
   - Try author names or book titles
   - Use category filters to narrow down results

2. **Bookmarking**
   - Bookmark important pages for quick access
   - Organize bookmarks by topic or project
   - Use bookmarks to track reading progress

3. **Downloading**
   - Download books for offline reading
   - Check file size before downloading
   - Ensure you have sufficient storage space

### For Meeting Participants

1. **Before Meetings**
   - Test your internet connection
   - Close unnecessary applications
   - Prepare any materials you want to share

2. **During Meetings**
   - Use clear, concise messages
   - Be respectful of other participants
   - Use typing indicators to show you're responding

3. **After Meetings**
   - Review chat history if needed
   - Save important information
   - Follow up on action items

## Troubleshooting

### Common Issues

1. **Login Problems**
   - Check your email and password
   - Ensure caps lock is off
   - Try resetting your password

2. **Book Loading Issues**
   - Check your internet connection
   - Try refreshing the page
   - Clear your browser cache

3. **Meeting Connection Issues**
   - Refresh the meeting page
   - Check your internet connection
   - Try joining again

4. **Chat Not Working**
   - Refresh the page
   - Check if you're still connected
   - Try sending a test message

### Getting Help

1. **Contact Support**
   - Use the contact form on the website
   - Include details about your issue
   - Provide screenshots if helpful

2. **Check Status**
   - Look for system status updates
   - Check if other users are experiencing issues
   - Try again later if it's a temporary problem

## Keyboard Shortcuts

### General
- `Ctrl + /` - Open help
- `Esc` - Close modals/dialogs

### Library
- `Ctrl + F` - Search books
- `Ctrl + D` - Download current book
- `Ctrl + B` - Bookmark current page

### Meetings
- `Ctrl + M` - Open meeting list
- `Ctrl + J` - Join meeting
- `Ctrl + L` - Leave meeting

### Chat
- `Enter` - Send message
- `Shift + Enter` - New line
- `Ctrl + A` - Select all text

## Privacy and Security

### Your Data
- Your personal information is protected
- Messages are encrypted in transit
- Files are stored securely

### Account Security
- Use a strong, unique password
- Don't share your login credentials
- Log out when using shared computers

### Content Sharing
- Only share appropriate content
- Respect copyright laws
- Don't share personal information of others
