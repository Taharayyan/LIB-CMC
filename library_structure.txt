📋 DATABASE SCHEMA OVERVIEW:

TABLES:
├── users
│   ├── id (PRIMARY KEY, UUID)
│   ├── username (UNIQUE)
│   ├── email (UNIQUE)
│   ├── password_hash
│   ├── role (admin/user/guest)
│   ├── avatar_url
│   ├── created_at
│   └── updated_at
│
├── books
│   ├── id (PRIMARY KEY, UUID)
│   ├── title
│   ├── author
│   ├── category
│   ├── description
│   ├── pdf_path
│   ├── cover_image
│   ├── file_size
│   ├── uploaded_by (FOREIGN KEY -> users.id)
│   ├── downloads_count
│   ├── created_at
│   └── updated_at
│
├── meetings
│   ├── id (PRIMARY KEY, UUID)
│   ├── title
│   ├── description
│   ├── scheduled_at
│   ├── duration (minutes)
│   ├── created_by (FOREIGN KEY -> users.id)
│   ├── room_url
│   ├── status (scheduled/ongoing/completed/cancelled)
│   ├── created_at
│   └── updated_at
│
├── chat_messages
│   ├── id (PRIMARY KEY, UUID)
│   ├── meeting_id (FOREIGN KEY -> meetings.id)
│   ├── user_id (FOREIGN KEY -> users.id)
│   ├── message (TEXT)
│   ├── message_type (text/file/image)
│   ├── created_at
│   └── updated_at
│
├── bookmarks
│   ├── id (PRIMARY KEY, UUID)
│   ├── user_id (FOREIGN KEY -> users.id)
│   ├── book_id (FOREIGN KEY -> books.id)
│   ├── page_number
│   ├── created_at
│   └── UNIQUE(user_id, book_id)
│
├── meeting_participants
│   ├── id (PRIMARY KEY, UUID)
│   ├── meeting_id (FOREIGN KEY -> meetings.id)
│   ├── user_id (FOREIGN KEY -> users.id)
│   ├── joined_at
│   ├── left_at
│   └── UNIQUE(meeting_id, user_id)
│
└── notifications
    ├── id (PRIMARY KEY, UUID)
    ├── user_id (FOREIGN KEY -> users.id)
    ├── type (meeting/book/system)
    ├── message
    ├── read (BOOLEAN)
    ├── created_at
    └── updated_at

🔧 TECHNOLOGY STACK:

Backend (Node.js):
- Express.js (Web Framework)
- Socket.IO (Real-time communication)
- Sequelize/Prisma (ORM)
- PostgreSQL/MySQL/MongoDB
- JWT (Authentication)
- Bcrypt (Password hashing)
- Multer (File uploads)
- PDF-lib (PDF processing)
- Nodemailer (Email service)
- Joi/Yup (Validation)

Frontend:
- React.js (Vite)
- Tailwind CSS
- Socket.IO Client
- React Router v6
- Axios
- React PDF (PDF viewing)
- React Hook Form
- React Query/SWR
- Zustand/Context API

DevOps:
- Docker & Docker Compose
- Nginx (Reverse proxy)
- PM2 (Process manager)
- Jest/Mocha (Testing)
